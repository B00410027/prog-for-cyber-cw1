Program:
This python program will prompt the user to guess a username and password. If both are guessed correctly an event log will be outputted and the program will end. If both are not guesses correctly an event log will be outputted and the user will be prompted to try again and the program wont end until the correct inputs are entered.

Code:
The user will input a username and password, if both inputs are correct then a successful login message will output and the program will end. If either and/or both inputs are incorrect then a failed login message will output, the user will then be prompted again until both username and password are correct.

How To Run:
1. Run code.
2. Input username and password.

3.1. If both inputs are correct, successful login output message, program ends.
3.2. If both and/or one input is incorrect, failed login output message, program ends.
