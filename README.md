This repository is made up of the main branch with 5 branch, 

Branch - Task 1 - Security Tool:
This python program will make the user navigate a menu with 4 options. The options are 1. Security Event Counter, 2. Brute Force Simulation, 3. Login Authentication, 4. Exit.
1. Security Event Counter
   The user will be prompted to guess the password 10 times. After the 10 attempts a security alert will output depending on the percentage of incorrect guesses.
2. Brute Force Simulation
   The user will be prompted to guess the password. They have 5 attempts. A message will output depending on the user input.
3. Login Authentication
   The user will be prompted to guess the username and password. They have 3 attempts. Authentication is only successful is both username and password are guessed correctly.
4. Exit
   The user will exit the program.

Branch - Task 2 - Security Event Logger:
This python program will prompt the user to guess a username and password. If both are guessed correctly an event log will be outputted and the program will end. If both are not guesses correctly an event log will be outputted and the user will be prompted to try again and the program wont end until the correct inputs are entered.

Branch - Task 3 - IP Address Validator:
This python program will prompt the user to input an IP address, if the input meets the criteria a valid IP message will be outputted. If the input does not meet the criteria then an invalid IP message will outputted.

Branch - Task 4 - Security Incident Manager:
This python program has a dictionary with key: value pairs already in it. The program will add a new key: value pair, modify an existing value and it will also delete a key: value pair.

Branch - Task 5 - Cyber Security Utilities:
This python program will prompt the user to input an IP address and a password. If the IP address meets the criteria a valid IP message will be outputted. If the IP address does not meet the criteria an invalid IP message will be outputted. If the password meets the criteria a password accepted message will be outputted. If the password does not meet the criteria an invalid password message will be outputted along with a random password between 10-16 characters long.
